# 🔐 Password Generator

A sleek, responsive, and interactive web application designed to generate secure, customizable passwords instantly. Try out the live application below!

🌐 **[Live Demo](https://anaskhan786i.github.io/Password-Generator/)**

---

## ✨ Features

* 🎚️ **Dynamic Length Control:** Adjust password length from 1 to 20 characters using a fluid slider.
* 🎛️ **Granular Customization:** Toggle uppercase letters, lowercase letters, numbers, and special symbols.
* 📊 **Strength Indicator:** Visual indicator shifts color dynamically based on password complexity.
* 📋 **One-Click Copy:** Fast clipboard integration via the dedicated copy button.
* 🎨 **Modern UI:** Vibrant gradient theme built with pure CSS.

---

## 🚀 Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Custom layouts, responsive styling, and modern UI variables.
* **JavaScript (ES6):** Logic generation, DOM manipulation, and dynamic state tracking.

---

## 🛠️ Installation & Local Setup

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd Password-Generator
   ```
3. Open `index.html` directly in your web browser.
